# A-Speech-and-Web-Controlled-Quadruped-Surveillance-Robot-Using-Raspberry-Pi-Zero-W-and-Arduino-Nano
Built a multi-modal quadruped robot using Arduino Nano for servo-based gait control and Raspberry Pi Zero W for wireless video streaming using a Pi Camera. Added voice-controlled movement and mobile-based remote control, enabling smooth locomotion, live monitoring, and human–robot interaction.
